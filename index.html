Panel de Administración

Un panel que lee todos tus comprobantes desde una Google Sheet y los muestra con login, gráficos, comparación mensual e informe exportable a PDF. Un solo backend con doPost (guardar) + doGet (leer), y un archivo HTML aparte para el panel.

Login Gráficos Leer datos (doGet) PDF mensual

¿Qué vamos a construir?

Un panel de administración que trae toda tu planilla de comprobantes y la muestra en un tablero. El backend (Apps Script) lleva las dos funciones de una sola vez: doPost para guardar y doGet para leer. Después armás el prompt de acá abajo —se completa solo a medida que marcás cada paso— y la IA te genera el HTML del panel.

El backend (Apps Script) es siempre el mismo. No le pidas a la IA que lo invente ni lo modifique: pegá exactamente el código del Paso 2, que ya trae doPost + doGet juntos. Lo único que cambia entre proyectos es el HTML del panel.

Truco para ahorrar tokens. Si ya generaste antes un formulario de carga con una IA, pedile en el mismo chat que reutilice ese HTML y solo le sume estas funciones nuevas (login, doGet, gráficos, PDF), en vez de escribir todo de cero. Si te quedaste sin cupo, pasá el mismo prompt a otra herramienta gratuita: el paso a paso es igual.
